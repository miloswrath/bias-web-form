# Implementation Plan: Post-Undergraduate Plans Survey

**Branch**: `001-web-survey` | **Date**: 2026-03-31 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `specs/001-web-survey/spec.md`

## Summary

Build a 6-question anonymous web survey on post-undergraduate plans using Next.js App Router,
Tailwind CSS, and Supabase as the persistence layer. Responses are saved via a Server Action;
a results page renders aggregated insights as SVG charts with no additional charting dependencies.

## Technical Context

**Language/Version**: TypeScript 5 / Node.js (via Nix flake)
**Primary Dependencies**: Next.js 16 (App Router), React 19, @supabase/supabase-js v2, Tailwind CSS v4
**Storage**: PostgreSQL 15 via Supabase (local: `postgresql://postgres:postgres@127.0.0.1:54322/postgres`)
**Testing**: Unit tests optional; none requested for this feature
**Target Platform**: Desktop-first web browser (Next.js dev server at http://localhost:3000)
**Project Type**: Web application (fullstack Next.js)
**Performance Goals**: Submission persisted within 5 s; results page renders within 3 s (<1000 responses)
**Constraints**: No new npm dependencies; server-side Supabase access only (no NEXT_PUBLIC_ keys exposed)
**Scale/Scope**: ~50–200 anonymous responses; single-semester use
